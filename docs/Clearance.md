# نظام براءة الذمة والعهد العينية — CLEARANCE (`6.iajaward.org`)

> آخر تحديث: 2026-10-26. يحل محل سكربت Google Apps Script وورقة Google Sheet، بنفس طريقة تشغيل بقية أنظمة iajaward.org.

| البند | القيمة |
|---|---|
| العنوان | `https://6.iajaward.org` (الدخول: `/login`، المدير العام: `/super/login`) |
| المنفذ | `8006` |
| المجلد على الكمبيوتر | `C:\Clearance` |
| المستودع | `AcsVe/Clearance` |
| قاعدة البيانات | SQLite: `data\clearance.db` (والمرفقات في `data\uploads`) |
| البريد | Microsoft Graph (`MS_TENANT_ID` / `MS_CLIENT_ID` / `MS_CLIENT_SECRET` / `MS_SENDER_EMAIL` في `config.env`) |
| النسخ الاحتياطي | كل ساعة إلى مجلد Google Drive المحدد في `BACKUP_DIR` (مثل `G:\My Drive\RAS-Clearance`) |
| الهاتف الاحتياطي | النفق `clearance-standby` |

## 1) التثبيت على كمبيوتر المدرسة (مرة واحدة)

1. حمّل المستودع إلى `C:\Clearance` (أو `git clone https://github.com/AcsVe/Clearance C:\Clearance`).
2. شغّل **`1_setup.bat`**، وهو يقوم بكل شيء بالترتيب:
   - يجد Python ويثبت المتطلبات.
   - يكتب `config.env`: يأخذ رمز Cloudflare وإعدادات البريد (Microsoft Graph) ومجلد Drive من الأنظمة الأخرى الموجودة على الجهاز، ويسأل فقط عن الناقص.
   - ينشئ **المدير العام** (`root`)، ثم **أول منظمة** (الجمعية الثقافية العربية / مدرسة الرائد العربي) ومديرها.
   - يعرض **استيراد بيانات Google Sheet القديمة** (اختياري، انظر البند 4).
   - يضبط نفق Cloudflare للعنوان `6.iajaward.org` على المنفذ 8006.
3. **`3_autostart.bat`** (كمسؤول): تشغيل تلقائي عند بدء الجهاز + نسخ احتياطي كل ساعة.
4. افتح `https://6.iajaward.org/login`.

> الدخول يعمل عبر **https** فقط (ملفات تعريف الارتباط آمنة)، لذلك لا تفتح `http://localhost:8006/login` لتسجيل الدخول.
> لا تلصق قيم `config.env` في أي محادثة أو بريد.

## 2) الإعداد داخل النظام (بالترتيب)

1. **الإدارة ← الإعدادات:** الاسم (الطويل يظهر تحت الشعار على عدة أسطر)، اللون الأساسي (الافتراضي أزرق `#0C67EC`)، الشعاران — إلى أن يُرفع شعار تظهر **أيقونة النظام** (مستند عليه ختم صح)، وخيار «إزالة الشعار» يعيدها — تذييل البريد، تذييل النموذج المطبوع («نموذج ر ع ع - 1 2026»). وتعرض الصفحة حالة **Microsoft Graph** (Tenant ID وClient ID وClient Secret من `config.env`) دون إظهار القيم. ملاحظة: إن لم يُرفع شعار المدرسة من قبل فارفعه هنا، لأن الشعار الاحتياطي أصبح أيقونة النظام.
2. **الإدارة ← الأقسام:** أضف الأقسام وبريد كل قسم. يجب وجود قسم واحد فعّال من نوع **شؤون الموظفين** وواحد من نوع **المحاسبة**.
3. **الموظفون:** أضف الموظفين واحداً واحداً، أو الصق قائمة من Excel، أو ارفع ملف Excel/CSV (زر «نموذج ملف الاستيراد» يعطي الأعمدة).
4. **الإدارة ← المستخدمون:** أنشئ حسابات المسؤولين وأسند لكل منهم دوره وقسمه، أو من **الموظفون** حدّد الموظفين ← «إنشاء حسابات دخول» (يصل كل موظف رابط تعيين كلمة المرور).

### الأدوار الافتراضية (قابلة للتعديل من «الأدوار والصلاحيات»)

| الدور | المهام |
|---|---|
| مدير النظام | كل شيء |
| شؤون الموظفين | إنشاء نماذج براءة الذمة ومتابعتها (تذكير، إقفال، إلغاء، إرسال للمحاسبة)، سجل الموظفين، عرض كل العهد، التقارير |
| المحاسبة | التسوية المالية، توقيع صف قسم المحاسبة |
| مسؤول قسم | توقيع براءة الذمة لقسمه، تسليم واسترجاع عهد قسمه واستيرادها |
| موظف / مستلم | «عهدي»: عهده ونماذجه فقط |

## 3) سير العمل

**براءة الذمة**
1. شؤون الموظفين: **براءة الذمة ← نموذج جديد** ← اختيار الموظف من السجل (تُملأ بياناته تلقائياً) ← تاريخ الاستقالة ← الأقسام المطلوبة.
2. يصل الموظفَ بريدٌ برقمه المرجعي (`CLR-2026-XXXXXX`)، ويصل كلَّ قسم عادي بريدٌ بزر **«فتح صفحة التوقيع»** (رابط خاص بالقسم وبالنموذج، لا يحتاج دخولاً)، ويعرض البريد والصفحة **العهد غير المسترجعة** على الموظف لدى ذلك القسم.
3. كل قسم يختار **خالية الذمة** أو **معلق** (مع سبب إلزامي)، من الرابط أو من **بوابة الأقسام** بعد الدخول. يمكن تعديل الرد ما دام النموذج مفتوحاً.
4. عند اكتمال كل الردود يصبح النموذج **مكتمل**، ويصل الموظفَ وشؤونَ الموظفين والمحاسبةَ بريدٌ: خالية، أو قائمة الأقسام المعلِّقة وملاحظاتها.
5. شؤون الموظفين: **تذكير** المتأخرين (ويُرسل تذكير تلقائي كل 3 أيام)، **إرسال إلى المحاسبة** بملاحظة، **إقفال** أو **إلغاء**.
6. المحاسبة: **بوابة المحاسبة ← تسوية وإقفال** بملاحظة ← يُقفل النموذج ويصل شؤونَ الموظفين بريد.
7. **طباعة:** «نموذج براءة الذمة»، أو «إثبات تسوية مالية» بعد التسوية، مع توقيعات شؤون الموظفين والمحاسبة والموظف.

**العهد العينية**
- **العهد ← تسليم عهدة:** العهدة، الكمية، الرقم التسلسلي، المستلم من السجل، القسم، التاريخ ← بريد للمستلم وللقسم ولمسلِّم العهدة.
- **استرجاع** عهدة أو عدة عهد دفعة واحدة ← بريد للجميع. **طباعة الإيصالات** لعهدة أو للمحدد كله.
- **إضافة قائمة أو استيراد ملف** للعهد الورقية القديمة.

**في كل القوائم:** تثبيت رؤوس الأعمدة، تصفية لكل عمود، ترتيب بالضغط على العنوان، بحث عام، وتحديد ← إجراءات جماعية (تفعيل/إيقاف/حذف/…).
**الرئيسية:** أرقام قابلة للضغط تفتح القائمة المقصودة مُصفّاة (مثلاً «مكتملة — فيها تعليق»، «عهد على موظفين في إجراءات براءة الذمة»، «موظفون بلا بريد»).
**الواجهة** (نمط appace، كنظام غياب الطلبة): قائمة جانبية ثابتة مجمّعة (العمل اليومي، العهد والموظفون، الإدارة) بأيقونات Font Awesome، وشريط علوي فيه عنوان الصفحة وقائمة المستخدم (تغيير كلمة المرور، تسجيل الخروج). على الهاتف (أقل من 992px) تصبح القائمة درجاً جانبياً يُفتح بزر ☰ ويُغلق بالخلفية أو Esc، والجداول تُمرَّر داخل إطارها. صفحات الدخول ونسيان كلمة المرور ودخول المدير العام، و**صفحة التوقيع من رابط البريد** لمن لم يسجّل الدخول، وصفحات الخطأ: تدرّج أزرق وبطاقة فيها دائرة الشعار وأيقونات الحقول وزر إظهار كلمة المرور. تسجيل الخروج لا يفشل أبداً بخطأ CSRF، وأي نموذج قديم يعود إلى صفحته برسالة «انتهت صلاحية الصفحة — أعد المحاولة». الملفات: `templates/base.html`، `templates/_brand_logo.html`، `static/brand/system.svg`، `static/css/app.css` (`--primary`)، `static/js/app.js`.

**حماية البيانات عند الحذف:** لا يُحذف قسم له ردود أو عهد أو موظفون (يُوقف بدلاً من ذلك)، ولا موظف عليه عهد غير مسترجعة، ولا نموذج عليه توقيعات ما لم يُلغَ أولاً، ولا آخر مدير للنظام، ولا الحساب الذي تستخدمه.

## 4) استيراد بيانات Google Sheet القديمة

1. في Google Sheets: **ملف ← تنزيل ← Microsoft Excel (.xlsx)**.
2. إما **الإدارة ← الإعدادات ← استيراد من Google Sheet** ورفع الملف، أو على الكمبيوتر: `python ops\import_sheets.py الملف.xlsx`.

يُستورد: «الاقسام» (بالكود)، «النماذج» و«الردود» (بالمعرف FORM-…؛ التواريخ الهجرية تُحوَّل للميلادي؛ «تسوية محاسبة: …» تُصبح تسوية مسجّلة)، «العهد» (بالمعرف CUST-…)، ويُضاف موظفو النماذج إلى السجل كموظفين موقوفين. إعادة الاستيراد لا تكرر شيئاً ولا تُرسل بريداً.

## 5) للمطوّر

- Flask 3 + SQLAlchemy + Alembic (`migrations/`)، Waitress (`serve.py`)، APScheduler (`jobs.py`)، Jinja RTL.
- **عزل المنظمات** (`tenancy.py`): كل جدول فيه `tenant_id`، وكل استعلام يُصفّى تلقائياً، و`get_scoped()` بدل `db.session.get()` للسجلات.
- CSP صارم (`script-src 'self'`): لا JavaScript داخل الصفحات؛ السلوك في `static/js/table.js` (الجداول والبطاقات والتحديد الجماعي) و`static/js/clearance.js`.
- قواعد سير العمل في `services/clearance.py` (تستخدمها الصفحات والمجدول)، والاستيراد في `services/sheets_import.py` و`utils/tabular.py`.
- الاختبارات: `python -m pytest -q` (SQLite افتراضياً، أو PostgreSQL عبر `TEST_DATABASE_URL`).

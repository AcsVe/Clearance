# نظام براءة الذمة والعهد العينية

تطبيق Flask مستقل يحل محل سكربت Google Apps Script، بنفس معمارية نظام حجز القاعات (venues):
Flask + SQLAlchemy + Jinja (RTL) + PostgreSQL، وwaitress محليًا على Windows خلف Caddy.

## حالة المراحل

| المرحلة | الحالة |
|---|---|
| 1. الأساس: المنظمات، الدخول، الأدوار والصلاحيات، الأقسام، التدقيق | ✅ مكتملة ومختبرة |
| 2. براءة الذمة | ✅ مكتملة ومختبرة |
| 3. العهد العينية + الاستيراد من Google Sheets | ✅ مكتملة ومختبرة |
| 4. OCR للعهد الورقية (محلي، مجاني) | ⏳ بانتظار صور جداول حقيقية |
| 5. الإشعارات والتذكيرات | ✅ مكتملة ومختبرة |
| 6. حزمة النشر المحلي | ⏳ بانتظار حزمة venues_local_server |

## الأمان (ما تغيّر عن السكربت)

- لا رموز PIN ثابتة ولا دخول بكود القسم: حسابات بأسماء مستخدمين وكلمات مرور مشفّرة (scrypt).
- قفل الحساب بعد 5 محاولات فاشلة لمدة 15 دقيقة، وحد لعدد المحاولات من نفس الجهاز.
- إعادة تعيين كلمة المرور برابط لمرة واحدة صالح ساعة، ويُخزَّن منه الـ hash فقط.
- الروابط المرسلة بالبريد تُبنى من `BASE_URL` فقط، لا من ترويسات الطلب.
- حماية CSRF لكل النماذج، وترويسات أمان (CSP يمنع السكربتات المضمّنة).
- كل القيم في الصفحات والبريد والطباعة مُهرَّبة (Jinja autoescape).
- كل إجراء يُسجَّل في سجل التدقيق، وكل محاولة بريد تُسجَّل مع سبب الفشل.

## عزل المنظمات

`tenancy.py` يفرض `tenant_id` على كل استعلام ORM (قراءة وتعديل وحذف جماعي وتحميل علاقات)،
ويرفض أي كتابة لسجل منظمة أخرى. أي وصول بلا منظمة محددة يرفع خطأ بدل إرجاع كل البيانات.
الاختبار `test_every_data_table_is_tenant_scoped` يفشل إن أضيف جدول جديد بدون `tenant_id`.

## التشغيل للتطوير

```bash
pip install -r requirements-dev.txt
cp config.env.example config.env    # واملأ القيم
flask --app app:create_app db upgrade
flask --app app:create_app create-superadmin root   # يسأل عن كلمة المرور بشكل مخفي
python run_server.py
```

ثم: `/super/login` لإنشاء المنظمة ومديرها الأول، و`/login` لدخول مستخدمي المنظمة.

## نقل البيانات من Google Sheets

1. من Google Sheets صدّر كل ورقة: File ← Download ← CSV، للأوراق: الاقسام، النماذج، الردود، العهد.
2. ضع الملفات الأربعة في مجلد واحد على الخادم (أسماء Google مثل `اسم الملف - العهد.csv` مقبولة).
3. تشغيل تجريبي (لا يكتب شيئًا، يعرض الأعداد والتحذيرات):

```bash
flask --app app:create_app import-sheets raed --dir C:\Clearance\import --report import_report.txt
```

4. بعد مراجعة التقرير: أعد الأمر نفسه مع `--commit`.

- الأعمدة تُقرأ بالترتيب كما في السكربت، فتغيير عناوينها لا يهم.
- التواريخ الهجرية التي كتبها السكربت (`ar-SA`) تُحوَّل لميلادي (أم القرى)، والنص الأصلي يبقى محفوظًا.
- إعادة التشغيل آمنة: ما سبق استيراده يُتجاوز ولا يتكرر.
- ملاحظة "تسوية محاسبة: ..." تُفصل عن ملاحظة شؤون الموظفين.
- لتنزيل الشعارين القديمين من Google Drive: `flask --app app:create_app fetch-drive-logos raed`
